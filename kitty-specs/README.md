# kitty-specs

Spec Kitty mission artifacts for this repository. Each subdirectory is one
mission: a numbered slug (e.g. `001-issue-driven-accessibility-scanner`)
containing `spec.md`, `plan.md`, `tasks.md`, and supporting research,
data-model, quickstart, and checklist files produced by the
specify -> plan -> tasks -> implement -> review workflow.

See `.kittify/charter/charter.md` for project governance and
`.kittify/AGENTS.md` for agent rules that apply while working in a mission.
